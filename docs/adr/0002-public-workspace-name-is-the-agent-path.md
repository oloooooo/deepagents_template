# `/public/` 用公共空间名做路径，公共空间的 name 因此不可变

agent 看到的公共空间挂载点是 `/public/{公共空间名}/...`。用可读的名字而不是 uuid，是因为模型要自己
决定读哪个目录，uuid 对它是纯噪音。代价是这个 name 变成了地址的一部分：改名会让所有已存在的路径失效
（历史会话里引用的、用户文档里写的），所以公共空间的 name 一律不可变 —— super 只能删了重建。

REST 侧仍然用 id 寻址，两者服务不同对象：一个是程序化客户端，一个是模型的可读性。

**Consequences**：`Workspace` 可以改名，`PublicWorkspace` 不能。两套空间的 API 在这一点上不一致，
是有意的，别去「修正」它。
